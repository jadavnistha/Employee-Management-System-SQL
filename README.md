# Employee Management System SQL Project

## 📌 Project Overview

This project demonstrates SQL-based analysis of employee and
department data using MySQL.

The project includes employee records, department information,
budget analysis, employee filtering, joins, aggregation,
data manipulation, and views.

## 🛠️ Tools & Technologies

- MySQL
- SQL
- dBeaver

## 🗄️ Database Structure

The project contains two main tables:

- Employee
- Department

The Employee table contains employee information such as
employee ID, first name, last name, and department code.

The Department table contains department code, department name,
and department budget.

## 📊 Key Analysis Performed

- Employee count analysis
- Department budget analysis
- Employee and department filtering
- Employee search using names
- Pattern matching using LIKE
- Sorting and limiting results
- Department-wise employee analysis
- Budget analysis
- Employee and department JOIN operations
- Creating and modifying tables
- Data type modification
- Creating SQL views
